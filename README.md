# SDLookingGlass v1.0

A fork of [my previous fork](https://github.com/nectarine5035/KernelUNOwithSD) of KernelUNO by [Arc1011](https://github.com/Arc1011/KernelUNO). This is my personal project to adapt the kernel to the Teensy 4.1, using an SD card in the built-in port, and adding more terminal features.


# Commands:

- `ls` - List files
- `cd` - Change directory
- `pwd` - Print working directory
- `mkdir` - Make directory
- `touch` - Create file
- `cat` - Read file text
- `echo` - Echo text to terminal
- `echo [text] > [file]`  -- Add text to file
- `rm` - Remove file or directory
- `info` - File info
- `sh` - Run shell script
- `sh [file]`  -- run script (use ; as line separator)
- `uptime` - Show uptime
- `uname` - Show device info
- `dmesg` - Show kernel messages
- `df`, `free` - Show free disk space
- `whoami` - Show username
- `clear` - Clear terminal
- `reboot` - Reboot device
- `alias` - Create command alias
